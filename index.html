3. Interface Options

Read this if you are configuring over the network. The settings below apply to every port in the range, including whichever one carries your uplink to the rest of the network. BPDU guard will then shut that port down the moment it hears from the switch upstream — and you lose this switch, and everything behind it, from wherever you are sitting. Name your uplink here to exclude it, or apply the config from the console instead.

▼ 4. Security

The password for enable mode. The switch stores it hashed — but the file this tool generates contains it in plain text, so delete that file once you have applied it.

Required before a device will generate an SSH key. Any internal name works.

Without this you cannot log in over SSH. Generating a key is not the same as having an account — leave these blank and you will be locked out of remote access after the reload.

Encrypts stored passwords, turns off the built-in web server, and puts portfast + BPDU guard on access ports so a switch plugged into a desk port cannot take the network down.
